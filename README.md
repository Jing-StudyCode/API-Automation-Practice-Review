# Kdtx API Automation Practice Review

基于 **Python + Requests** 的接口自动化业务流联调实战脚本。

## 💡 项目说明
本项目针对「客达天下」系统，实现了一条完整的端到端业务链路测试：
1. **获取验证码**：GET 请求获取 `uuid`。
2. **登录鉴权**：POST 请求获取 `token`，封装至 Headers 解决鉴权。
3. **新增课程**：POST 请求创建新课程数据。
4. **动态查询**：GET 请求查询课程列表，动态提取最新 `courseId`。
5. **上传文件**：POST 请求使用 `files` 参数上传附件，提取 `fileName`。
6. **新增合同**：利用 `random` 生成唯一合同号，结合动态 ID 与附件名完成最终业务闭环。

## 🚀 核心技术点
- **绕过安全拦截**：利用 `User-Agent` 伪装突破 WAF 防火墙（解决 405 报错）。
- **参数动态关联**：通过 JSON 解析（如 `rows[0].get('id')`）实现接口间的参数传递。
- **唯一性校验处理**：使用 `random.randint()` 解决重复执行导致的合同编号冲突问题。
- **文件上传处理**：掌握 `files={"file": open("...", "rb")}` 的二进制流上传方式。
